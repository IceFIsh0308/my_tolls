🗂 工具包结构

视频内容总结工具/ ├── 一键启动.command ← 双击这个启动（自动装环境+开浏览器） ├── server.py 本地 Web 服务 (127.0.0.1:8765) ├── index.html 网页界面（拖视频/选类型/看进度/下载结果） ├── 视频内容总结.py 命令行入口（进阶用） ├── 服务商管理.py 添加/切换 API 服务商（通义/DeepSeek等） ├── 平台预设.json 内置平台库（8家 OpenAI 兼容平台） ├── 类型预设.json 5种视频类型 → 抽帧策略 ├── AI配置.json 你的 API Key / 服务商配置（隐私） ├── core/ 核心模块（抽帧/OCR/转写/总结/config） └── 使用说明.md 详细文档
📌 注意：AI配置.json 含你的 API Key，不要上传到公开 GitHub。

🐙 GitHub 托管（可选）

工具本体需要本地运行（ffmpeg + AI 模型），不能像纯前端下载器那样直接挂在 GitHub Pages 在线使用。但可以用 GitHub 做代码托管与版本管理：
1. 新建私有仓库（如 video-summarizer）
2. 推送工具包内容（.gitignore 已挡掉 .venv/bin/产出）
3. 换电脑：git clone 或下载 zip → 双击启动脚本
git init && git add . && git commit -m "v0.3" git remote add origin git@github.com:你的用户名/video-summarizer.git git push -u origin main
